# The earlier, larger version of this fugue

Until October 2026 the cycle's rule was "Fugue N has N+1 real voices". The
owner found the textures too thick, so the rule became "at most one voice more
than Bach's fugue in the same key (WTC I)", and this fugue was recomposed.

This folder keeps the earlier version for comparison: its source (fugue.py,
which expects to sit one folder up, so rebuild it from git history if
needed), the built score, its NOTES and reviews, and its renders.
